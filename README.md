# CS2 Death Switch

CS2 死了就切屏。监听《反恐精英 2》的比赛状态，你一旦阵亡，自动切到你提前设好的网页或本地程序；复活或者新回合开始后，暂停当前播放的媒体，把你拉回游戏。

## 这套是干嘛的

原版 CS2Toolkit 是个 Python 工具，功能堆得比较满。这个仓库是用 Rust 从头重写的版本，只保留了「阵亡切屏」这一条核心链路，资源替换、音效、叠加层、桌宠、预设这些全都砍掉了，代码更干净，也更不容易出问题。

界面是简体中文，数据只写在自己的配置目录，不碰旧版 CS2Toolkit 留下的任何文件。

## 环境要求

- Windows 10 1809 及以上
- 安装好《反恐精英 2》
- 想自己编译的话再来个 Rust 1.85+

## 构建与运行

```powershell
cargo run --release
```

编译产物在 `target\release\cs2-death-switch.exe`，单文件、没有第三方依赖，拷到哪都能直接跑。

配置保存在：

```text
%LOCALAPPDATA%\CS2DeathSwitch\config.json
```

## 使用步骤

1. 打开程序。
2. 填一个网页地址，或者选一个本地程序。
3. 指定 CS2 安装目录（也可以让它自己找）。
4. 点一下「生成 GSI 配置」。
5. 重启 CS2，让配置生效。

生成的配置文件在 `game\csgo\cfg\gamestate_integration_cs2deathswitch.cfg`（位于 CS2 安装目录下），本机监听只绑定 `127.0.0.1`，默认端口 `3000`。如果端口被占用，可以在界面里改。

## 常见问题

- **中文显示成方块？** 程序启动时会从系统字库里找微软雅黑、黑体、宋体、等线，拿来兜底渲染中文。这几款全都没有的话中文就会变成方块，装个中文字体就好。
- **原理稳妥吗？** 首次收到 GSI 数据只建立基线、不会误切；掉血到 0 才触发一次切换；观战别人时不会切；延迟切换还没落地就复活了，这次切换会取消。
- **为什么切回去的是整个浏览器而不是某个标签页？** Windows 的媒体会话只能控制到"浏览器"这一层，系统没有可靠的接口让你挑里面某个标签。这个是系统的限制，不是 bug。

## 打包发布

```powershell
cargo build --release
```

把 `target\release\cs2-death-switch.exe` 和 `README.md`、`LICENSE` 放到一起打个 zip，就能当发布包了。也可以直接放裸 exe，反正没有依赖。
