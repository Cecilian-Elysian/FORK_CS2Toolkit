# CS2 工具箱 

一款专为CS2设计的多功能软件，让你的游戏体验变的个性化！

##  功能

### 开屏动画替换
- 支持自定义游戏启动时的开屏动画
- 支持 WEBM 格式视频文件
- 预设管理系统，方便快速切换

### 启动音效替换
- 替换游戏启动音效
- 支持多种音频格式
- 一键还原默认音效
- 音效预设保存和管理

### 字体替换
- 自定义游戏内字体
- 支持 TTF 格式字体文件
- 字体预设管理

### 实时音效播放
- 基于 Game State Integration（GSI） 
- 根据游戏事件实时播放音效
- 支持击杀、死亡、C4安放等多种游戏事件

## 快速开始

### 系统要求
- Windows 10/11
- 已安装的CS2

## 使用说明

### 1. 首次使用
1. 启动程序后，点击"检测CS2路径"自动定位游戏安装位置
2. 如果自动检测失败，可手动选择CS2路径

### 2. 开屏动画替换
1. 切换到"开屏替换"页面
2. 选择 WEBM 格式的视频文件
3. 选择替换版本（国际服/国服/全部）
4. 点击"执行替换"完成操作

### 3. 音效替换
1. 切换到"音效替换"页面
2. 选择音频文件
3. 点击"替换"

### 4. 字体替换
1. 切换到"字体替换"页面
2. 选择 TTF 格式字体文件
3. 点击"替换"应用新字体

### 5. 实时音效播放
1. 切换到"游戏内音效"页面
2. 点击生成配置文件
3. 配置事件
4. 启动 GSI 服务器
5. 享受游戏

## 技术

- 基于 PySide6 和 qfluentwidgets 构建
- 支持明暗主题切换
- 支持预设保存、加载、删除功能
- 智能检测 CS2 安装路径
- 完整的 Game State Integration 支持
- 完善的错误提示和异常处理
